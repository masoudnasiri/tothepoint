# 30) Phase 12B - Cashflow Semantics Correction

## User-Reported Issue

UAT reported inconsistency and semantic mismatch in financial views:

- pre-decision commercial/procurement values appearing in cashflow contexts
- budget being interpreted in inflow-style totals
- dashboard/report/analytics numbers diverging by lifecycle state

## Correct Cashflow Semantics (Target)

- Budget is capacity, not customer inflow.
- Forecast must come only from committed lifecycle state (`LOCKED` decisions + planned schedules).
- Actual must come only from operational finance records (payment-in/payment-out/invoice paid events).
- Unified view must convert to IRR using exchange rates.
- Missing exchange rate must be flagged, not silently mixed.

## Incorrect Behaviors Found

1. `FORECAST` rows were not lifecycle-gated to locked decisions in multiple endpoints.
2. Dashboard totals mixed budget into inflow/net semantics.
3. Unified conversion fallback could silently include unconverted foreign amounts.
4. Reports financial summary lacked explicit monthly budget capacity series.

## Implemented Rules

### Forecast Inclusion Rule

- Include forecast cashflow only when tied to `finalized_decisions.status = LOCKED`.

### Actual Inclusion Rule

- Include actual cashflow only from `cashflow_events.forecast_type = ACTUAL` generated by operational finance flows.

### Budget Inclusion Rule

- Include monthly budget as a separate capacity series/total.
- Do not merge budget into inflow totals.

### Currency Rule

- Unified mode: convert non-IRR values via exchange rate table.
- Missing rate: value is excluded from unified totals and warning is returned.
- Original mode: original currency values are preserved.

## Before / After Examples

### Before

- `GET /dashboard/cashflow?forecast_type=FORECAST` returned:
  - `summary.total_inflow = 49161499494688.0` (incorrect in budget-only state)
  - monthly `net_flow` equal to budget values even when inflow/outflow were zero.
- `FORECAST` values from `PROPOSED` decisions could appear in dashboard/analytics/export.
- Some unified conversions could silently fallback to non-converted amount.

### After

- `summary.total_inflow` = operational inflow only.
- `summary.total_budget` exposed separately.
- `summary.net_position` = inflow - outflow.
- `summary.net_with_budget` exposed separately for capacity view.
- In budget-only/pre-decision runtime:
  - `summary.total_inflow = 0.0`
  - `summary.total_outflow = 0.0`
  - `summary.total_budget = 49161499494688.0`
  - monthly `net_flow = 0.0`, monthly `capacity_flow = budget`.
- Forecast rows are lifecycle-filtered to committed decisions only.
- Missing exchange rates generate warnings and are not silently summed.
